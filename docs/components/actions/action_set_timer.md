# Action - Set Timer

The action **Set Timer** creates a timer in a compatible timer app installed on the device.

### Settings

#### Label

The label of the timer. [Variables are supported.](action_script.md#string-inline-expressions)

#### Duration

The duration of the timer (second granularity). [Variables are supported.](action_script.md#string-inline-expressions)

#### Skip UI

Whether or not the timer app should be displayed after setting the timer.
