# Action - Hide Custom Widget Overlay (Android Wear)

The action **Hide Custom Widget Overlay (Android Wear)** hides a previously shown overlay.

### Settings

#### Android Wear device

The device to hide the widget on. [Variables are supported.](action_script.md#string-inline-expressions)

#### Overlay name

The name/identification of the overlay to hide.

A variable is a container for a value that can be used in many actions and conditions to dynamically define a part of a text.
[See action Script for a description.](action_script.md#string-inline-expressions)

### Supplied Variables

- `widget_x_offset` — X-offset of the hidden widget.
- `widget_y_offset` — Y-offset of the hidden widget.
