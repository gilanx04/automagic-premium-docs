# Action - Post Tweet

The action **Post Tweet** posts a regular Twitter message.

Examples:

- Tweet your location every hour.

### Settings

#### Twitter Account

The Twitter account used to send the message.

#### Message

The message to send. [Variables are supported.](action_script.md#string-inline-expressions)

#### Image files

The images to attach to the tweet. [Variables are supported.](action_script.md#string-inline-expressions)
