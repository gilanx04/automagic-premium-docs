# Action - Unzip Files

The action **Unzip Files** unzips all files and folders contained in the ZIP file to the specified target folder.

Examples:

- Unzip all files in `archive.zip` to directory `/mnt/sdcard/xyz/`.

### Settings

#### ZIP File

The ZIP File to uncompress. [Variables are supported.](action_script.md#string-inline-expressions)

#### Target Directory

The absolute path of the target directory to unzip the archive to. [Variables are supported.](action_script.md#string-inline-expressions)

#### Show progress notification

Whether or not to show a notification on the statusbar indicating the progress of the operation.
