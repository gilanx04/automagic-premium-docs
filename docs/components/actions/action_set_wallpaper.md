# Action - Set Wallpaper

The action **Set Wallpaper** changes the wallpaper of the phone to the defined static image.

Examples:

- Change the wallpaper at home.
- Change the wallpaper when an SMS is received.

### Settings

#### Path to wallpaper image

The path to the image file to use as the wallpaper. [Variables are supported.](action_script.md#string-inline-expressions)

A variable is a container for a value that can be used in many actions and conditions to dynamically define a part of a text.
[See action Script for a description.](action_script.md#string-inline-expressions)

### Supplied Variables

- `wallpaper_path` — the path of the set wallpaper
