# Action - Set Alarm

The action **Set Alarm** creates an alarm in the alarm app available on the device.

Warning: Not all alarm apps support all options.

### Settings

#### Label

The label to use in the alarm. Not supported by all alarm apps. [Variables are supported.](action_script.md#string-inline-expressions)

#### Hour (0–23)

The hour to use in the alarm. [Variables are supported.](action_script.md#string-inline-expressions)

#### Minutes (0–59)

The minutes to use in the alarm. [Variables are supported.](action_script.md#string-inline-expressions)

#### Alarm

The alarm to play. Not supported by all alarm apps. [Variables are supported.](action_script.md#string-inline-expressions)

#### Vibrate

Whether or not the device should vibrate. Not supported by all alarm apps.

#### Skip UI

Whether or not the alarm app should be displayed after setting the alarm. Not supported by all alarm apps.
