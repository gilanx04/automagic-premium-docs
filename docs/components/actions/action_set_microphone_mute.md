# Action - Set Microphone Mute

The action **Set Microphone Mute** mutes or unmutes the microphone of the phone.

Examples:

- Mute the microphone when the device screen is facing down.

### Settings

#### Mute Microphone

Whether to mute or unmute the microphone.
