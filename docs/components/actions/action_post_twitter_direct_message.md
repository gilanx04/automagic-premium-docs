# Action - Post Twitter Direct Message

The action **Post Twitter Direct Message** posts a Twitter direct message to one recipient.

Examples:

- Tweet your location every hour to your wife.

### Settings

#### Twitter Account

The Twitter account used to send the message.

#### To

The recipient of the direct message (without leading @). [Variables are supported.](action_script.md#string-inline-expressions)

#### Message

The message to send. [Variables are supported.](action_script.md#string-inline-expressions)
