# Action - Reboot

The action **Reboot** restarts the device.

Warning: This function requires root access, is not officially supported by Android and might not work on all devices.

Examples:

- Restart the device every morning at 6am.

### Settings

#### Options

Options to pass to the kernel when the device is restarted. For example `recovery` to boot into recovery mode. [Variables are supported.](action_script.md#string-inline-expressions)
