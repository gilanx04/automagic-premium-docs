# Action - Message Dialog

The action **Message Dialog** shows a dialog with a message and an optional title.

Examples:

- Show the text of an incoming SMS directly in a dialog.

### Settings

#### Title

The optional title of the dialog. [Variables are supported.](action_script.md#string-inline-expressions)

#### Message

The message to show in the dialog. [Variables are supported.](action_script.md#string-inline-expressions)

#### Button Label

The label of the button. The button is not shown when the text is empty. [Variables are supported.](action_script.md#string-inline-expressions)

#### Activate Timeout

Whether an automatic timeout should automatically hide after the specified time.

#### Duration

The amount of time to automatically close the dialog and to continue the flow.
