# Action - Add WiFi Access Point

The action **Add WiFi Access Point** adds a new WiFi configuration and optionally connects to the new WiFi network.

Examples:

- Scan a barcode with WiFi connection information and directly connect to the new WiFi.

### Settings

#### SSID

The SSID of the Access Point. [Variables are supported.](action_script.md#string-inline-expressions)

#### Security

Whether to use WEP, WPA or no security. [Variables are supported.](action_script.md#string-inline-expressions)

#### Password

The password. [Variables are supported.](action_script.md#string-inline-expressions)

#### Activate

Whether or not to connect to the new WiFi network.
