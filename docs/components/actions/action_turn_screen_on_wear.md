# Action - Turn Screen On (Android Wear)

The action **Turn Screen On (Android Wear)** turns the screen on for a few seconds.

Examples:

- Turn the screen on when an SMS arrives.

### Settings

#### Android Wear device

The target device. [Variables are supported.](action_script.md#string-inline-expressions)
