# Panduan

Empat panduan ini berasal dari dokumentasi resmi Automagic yang dipulihkan dari arsip 2019. Mulailah dari konsep dasar, lalu praktik membuat flow, dan lanjutkan ke widget serta layar aplikasi.

| Urutan | Panduan | Isi | Cocok untuk |
| ---: | --- | --- | --- |
| 1 | [Konsep Dasar](base-concepts.md) | Flow, trigger, condition, action, variabel, dan cara kerja umum Automagic | Semua orang |
| 2 | [Membuat Flow Pertama](creating-the-first-flow.md) | Tutorial langkah demi langkah: notifikasi setiap 5 menit, lalu versi dengan waktu | Pemula yang ingin langsung praktik |
| 3 | [Membuat Widget Kustom](creating-a-custom-widget.md) | Widget, overlay, elemen teks, dan pembaruan otomatis | Pengguna yang ingin tampilan sendiri |
| 4 | [Layar Utama](main-screens.md) | Daftar flow, editor, log, pengaturan, dan navigasi aplikasi | Pengguna baru maupun lama |

## Urutan belajar yang disarankan

1. Baca [Konsep Dasar](base-concepts.md) sampai paham perbedaan trigger, condition, dan action.
2. Ikuti [Membuat Flow Pertama](creating-the-first-flow.md) tanpa melewati langkah.
3. Coba ubah flow tersebut: ganti trigger, tambah condition, atau ubah teks notifikasi.
4. Kalau ingin tampilan di layar utama, lanjut ke [Membuat Widget Kustom](creating-a-custom-widget.md).
5. Gunakan [Layar Utama](main-screens.md) sebagai referensi saat bingung dengan menu aplikasi.

> **Tips:** dokumentasi asli berbahasa Inggris. Istilah teknis seperti *flow*, *trigger*, *condition*, dan *action* sengaja dipertahankan agar cocok dengan nama di aplikasi. Penjelasan istilah ada di [Glosarium](../glossary.md).
