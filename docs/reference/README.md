# Referensi

Halaman referensi berisi pola, format, dan kemampuan teknis yang dipakai di banyak komponen. Gunakan bagian ini saat membutuhkan sintaks yang tepat.

| Referensi | Gunakan untuk | Contoh isi |
| --- | --- | --- |
| [Regular Expressions](regular-expressions.md) | Mencocokkan teks dengan pola | Karakter khusus, grup tangkapan, contoh pola |
| [Date Format Patterns](date-format-patterns.md) | Memformat tanggal dan waktu | `HH:mm`, `EEEE`, `yyyy-MM-dd` |
| [Number Format Patterns](number-format-patterns.md) | Memformat angka dan desimal | Pemisah ribuan, jumlah desimal, mata uang |
| [Script Examples](script-examples.md) | Menulis script di action **Script** | Manipulasi teks, angka, tanggal, dan list |
| [Device Idle / Doze Mode](device-idle-mode.md) | Memahami pembatasan daya Android | Doze, App Standby, dan dampaknya ke flow |
| [Device Owner](device-owner.md) | Fitur yang membutuhkan device owner | Cara menyiapkan dan kemampuannya |

## Kapan memakai halaman mana

- Teks tidak cocok dengan pola sederhana → [Regular Expressions](regular-expressions.md).
- Ingin menampilkan jam atau tanggal dengan format sendiri → [Date Format Patterns](date-format-patterns.md).
- Ingin membulatkan atau memformat angka → [Number Format Patterns](number-format-patterns.md).
- Butuh contoh kode untuk mengolah variabel → [Script Examples](script-examples.md).
- Flow sering berhenti saat layar mati → [Device Idle / Doze Mode](device-idle-mode.md).
- Aplikasi butuh izin istimewa → [Device Owner](device-owner.md).
