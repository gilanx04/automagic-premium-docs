# Changelog

## [1.0.0] — 2026-10-21

Rilis publik pertama arsip dokumentasi Automagic.

### Ditambahkan

- 127 halaman trigger, 88 halaman condition, dan 219 halaman action.
- 4 panduan: konsep dasar, flow pertama, widget kustom, dan layar utama.
- 6 halaman referensi: regex, format tanggal, format angka, contoh script, Doze mode, dan device owner.
- Katalog gabungan `docs/components/all-components.md`.
- Indeks per kategori dengan ringkasan setiap komponen.
- `catalog.json` untuk kebutuhan tooling.
- Glosarium dan FAQ dalam bahasa Indonesia.
- 56 gambar yang disimpan lokal di `docs/assets/`.
- Validator `scripts/validate_docs.py` dan workflow GitHub Actions.

### Catatan

- Dokumentasi dipulihkan dari Wayback Machine (arsip 2019–2020).
- 356 halaman komponen direkonstruksi dari `components_all_en.html` (capture 23 September 2020); 78 halaman berasal dari tangkapan individual.
- Teks asli dipertahankan dalam bahasa Inggris; navigasi berbahasa Indonesia.
